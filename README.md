## รายละเอียดโปรเจกต์ (Project Overview)
ระบบบันทึกข้อมูลรถของบุคลากรเพื่อออกสติกเกอร์เข้า–ออกวิทยาลัย

### ฟิลด์ข้อมูลที่กำหนด (Database Schema)
1. `plate_no` : ทะเบียนรถ
2. `type` : ประเภทรถ (รถยนต์ / รถจักรยานยนต์)
3. `brand_model` : ยี่ห้อ รุ่น
4. `color` : สี
5. `owner` : ชื่อเจ้าของ
6. `department` : แผนกวิชา
7. `status` : สถานะสติกเกอร์ (ออกแล้ว / รอออก / หมดอายุ)
